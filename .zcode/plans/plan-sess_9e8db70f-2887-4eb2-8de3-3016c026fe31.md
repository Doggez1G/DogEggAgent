# WebUI 彻底重新设计 — 项目/会话树 + 设置弹窗 + 右侧面板 + 删除功能

## 架构分析结论

**顺序会话切换方案**（不需要多 Agent）：`running` 守卫天然保护运行中切换（被拒绝而非崩溃）。cwd 持久化到会话文件，resume 恢复 cwd。TUI 零破坏，bridge 向后兼容扩展。

## 后端改动

### 1. session 加 cwd 持久化
- `agent/src/session/store.ts`：saveSession 加可选 `cwd` 参数，loadSession 返回 `cwd`
- `agent/src/session/list.ts`：listSessions 返回项加 `cwd`
- `agent/src/core/agent.ts`：resume 恢复 cwd + new_session 可选 cwd + saveSession 传 this.cwd

### 2. 新增删除会话功能
- `agent/src/session/store.ts`：新增 `deleteSession(id, baseDir)` —— `unlinkSync` 删 JSON 文件
- `agent/src/session/index.ts`：导出 deleteSession
- `bridge/src/contract/ui-to-agent.ts`：新增 `| { type: 'delete_session'; id: string }`
- `bridge/src/contract/agent-to-ui.ts`：新增 `| { type: 'session_deleted'; id: string }` 让 UI 知道删完了
- `agent/src/core/agent.ts`：send() 加 `case 'delete_session'`——run-guarded + 调 deleteSession + emit session_deleted + 重新 list_sessions

### 3. bridge 契约扩展（向后兼容）
- `new_session` 加 `cwd?: string`
- `session_list` sessions 加 `cwd?: string`

## 前端改动

### 4. 删除 Panel 概念，Settings 改为 modal
- `view-state.ts`：删 Panel，Modal 加 `| { kind: 'settings'; tab?: SettingsTab }`
- App 不再有 panel 切换——主区域永远是聊天

### 5. 侧栏重写为项目/会话树
- 按 cwd 分组会话为项目（折叠/展开）
- 每个项目右边 + 按钮添加新会话（new_session with cwd）
- 底部 + Add Project 打开 FsBrowser 选目录
- 点击会话 = resume_session
- 每个会话右边有删除按钮（Trash2 图标，点后确认弹窗 → delete_session）
- 项目级别有删除按钮（删除该 cwd 下所有会话，确认弹窗）
- 仍可整体收起为图标条

### 6. 右侧信息面板
- 新 grid area `info`：token 使用量 + 状态 + 工具调用列表 + provider/model
- 可收起

### 7. 聊天/输入框美化 + 停止按钮
- 停止按钮更醒目（已有 cancel 功能，视觉强化为运行时居中醒目红色按钮）
- 消息块更柔和的圆角卡片
- 输入框更大圆角

## Grid 布局
```
grid-template-columns: 240px 1fr 280px
grid-template-areas: 'sidebar topbar info' 'sidebar main info' 'sidebar input info'
```

## 对 TUI 影响：零破坏
- main.ts 不变，createChannelPair 不变
- /cd + new_session 自然支持项目切换
- TUI 可选加 /delete 命令（非必须）

## 对 bridge 影响：向后兼容
- new_session cwd 可选，旧 TUI 不传
- session_list 加 cwd? 字段，旧 TUI 忽略
- delete_session / session_deleted 是新增消息，旧 TUI 不用
- 流式消息完全不改
