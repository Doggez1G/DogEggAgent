# DogEggAgent WebUI 整体重新设计 — 实施计划

## 设计系统基线（已与用户确认）

| 维度 | 决定 |
|---|---|
| 风格 | Minimalism & Swiss Style + AI-Native UI |
| 三主题 | **Midnight**(暗, Indigo `#6366F1`, Zinc `#09090B`) / **Forest**(暗, Green `#22C55E`, Slate `#0F172A`) / **Dawn**(亮, Indigo, `#FAFAFA`) |
| 字体 | Inter(UI) + JetBrains Mono(代码) + Space Grotesk(品牌) |
| 间距 | `--sp-1` 4px → `--sp-8` 32px，8px 基数 |
| 字号 | `--fs-xs` 12 → `--fs-2xl` 32 |
| 圆角 | sm 4px / md 6px / lg 8px |
| 毛玻璃 | 中度：blur(8px) + rgba(0.85)，仅 modal/命令面板/浮层 |
| 布局 | 240px 侧栏 + 1fr 主区 + 280px 面板，40px 顶栏 |
| 顶栏 | 模型信息 + 工作目录 + 运行状态 + Cmd+K 入口 |
| 右侧面板 | 8 个可折叠 section（含新增 Files Touched） |
| 命令面板 | Cmd+K，含斜杠命令 + 会话切换 + 主题切换 + 快捷操作 |
| 设置 | 3 卡片堆叠（General / Providers & Models / Permissions），优化 model 行 |
| 品牌 | Egg+Paw 精化 + "DogEgg" wordmark + hover 微动效 |
| 组件系统 | primitives 层：Button/IconButton/Input/Card/Badge/Toggle/Tooltip |
| 状态层级 | 图标 + 形状 + 颜色三重表达 |
| token 间接层 | 保留 `token-map.ts` + `--color-token-*` 映射 |

## 不改的文件
- `bridge/`、`agent/`、`server/`、`ui/src/shared/` — 零改动
- 后端消息契约、reducer、block 模型、commands、config 导航全部不动

## P1: 设计 Token 基础（3 主题 CSS + global + animations）

### 文件操作
- **重命名** `catppuccin.css` → `midnight.css`，`ios-dark.css` → `forest.css`，`ios-light.css` → `dawn.css`
- **全部重写** 3 个主题 CSS 文件 + `global.css` + `animations.css`

### 每个主题 CSS 定义完整的 token 体系
```css
[data-theme='midnight'] {
  /* 颜色 */
  --color-bg: #09090B; --color-surface: #18181B; --color-surface-elevated: #27272A;
  --color-card: #1C1C1F; --color-text: #F4F4F5; --color-subtext: #A1A1AA;
  --color-accent: #6366F1; --color-accent-fg: #FFFFFF;
  --color-success: #22C55E; --color-warning: #FBBF24; --color-danger: #EF4444;
  --color-border: #27272A;
  /* 圆角 — Swiss style 方正 */
  --radius-sm: 4px; --radius-md: 6px; --radius-lg: 8px;
  /* 间距 scale — 8px 基数 */
  --sp-1: 4px; --sp-2: 8px; --sp-3: 12px; --sp-4: 16px; --sp-5: 20px; --sp-6: 24px; --sp-8: 32px;
  /* 字号 scale */
  --fs-xs: 12px; --fs-sm: 13px; --fs-base: 14px; --fs-md: 16px; --fs-lg: 18px; --fs-xl: 24px; --fs-2xl: 32px;
  /* 字体 */
  --font-sans: 'Inter', system-ui, sans-serif; --font-mono: 'JetBrains Mono', monospace;
  --font-display: 'Space Grotesk', var(--font-sans);
  /* 阴影 — 极少使用 */
  --shadow-sm: 0 1px 2px rgba(0,0,0,0.3); --shadow-md: 0 4px 12px rgba(0,0,0,0.4); --shadow-lg: 0 8px 24px rgba(0,0,0,0.5);
  /* z-index scale */
  --z-base: 0; --z-sticky: 10; --z-overlay: 50; --z-modal: 100;
  /* 动画时长 scale */
  --t-fast: 120ms; --t-normal: 200ms; --t-slow: 300ms;
  /* 毛玻璃 */
  --glass-bg: rgba(24,24,27,0.85); --glass-blur: 8px;
  /* 布局尺寸 token */
  --sidebar-w: 240px; --sidebar-collapsed-w: 48px; --info-w: 280px; --info-collapsed-w: 32px; --topbar-h: 40px;
  /* token 间接层映射（保留给 token-map.ts） */
  --color-token-accent: var(--color-accent); --color-token-text: var(--color-text);
  --color-token-cyan: #22D3EE; --color-token-yellow: var(--color-warning);
  --color-token-red: var(--color-danger); --color-token-subtext: var(--color-subtext);
}
```
Forest: bg `#0F172A`, surface `#1E293B`, elevated `#272F42`, accent `#22C55E`, cyan `#2DD4BF`
Dawn: bg `#FAFAFA`, surface `#FFFFFF`, **elevated `#F4F4F5`**（修复 ios-light hover 不可见 bug）, text `#18181B`, accent `#6366F1`, border `#E5E5E5`

### `:root` fallback block
在 `midnight.css` 顶部加 `:root` 块，复制 Midnight 的所有值作为 CSS 级 fallback（JS 未执行时的安全网）。

### global.css 重写
- reset + Google Fonts import（Inter + JetBrains Mono + Space Grotesk）
- body 基础（font-size 用 `var(--fs-base)`, bg/fg 用变量）
- scrollbar（width 8px，thumb 用 `--color-border`）
- `*:focus-visible:not(input):not(textarea):not(select)` → outline 2px accent（保留现有正确逻辑）
- `::selection` accent 色

### animations.css 重写
- **删除死代码**：`.sidebar-item`, `.transition-color`, `.panel-enter`, `.icon-bounce`, `.icon-rotate` 及对应 keyframes
- 保留使用的：`token-in`, `block-in`, `pulse-dot`, `pulse-bar`, `spin`, `modal-in`
- **修复 reduced-motion**：用通配 `*` 选择器覆盖所有 animation/transition，而非逐类列举
  ```css
  @media (prefers-reduced-motion: reduce) {
    *, *::before, *::after {
      animation-duration: 0.01ms !important; animation-iteration-count: 1 !important;
      transition-duration: 0.01ms !important;
    }
  }
  ```
- 所有 keyframes 移到此处集中管理（包括 info-panel 的 `spin`）

## P2: Primitives 组件层

### 新建 `ui/src/webui/components/primitives/`

**button.tsx + button.module.css**
```tsx
type Variant = 'primary' | 'secondary' | 'danger' | 'ghost'
<Button variant="primary" size="sm|md" onClick={...}>Label</Button>
```
- primary: accent bg, accent-fg text
- secondary: transparent bg, border, text color
- danger: danger bg
- ghost: transparent, subtext, hover surface-elevated
- 所有 variant 共享 padding/font/radius/transition，消除 app.module.css 三份重复

**icon-button.tsx**
```tsx
<IconButton icon={Settings} size={32} aria-label="Settings" onClick={...} />
```
- 统一 32×32（或可选 28），border-radius sm，hover surface-elevated，focus-visible outline
- 替代 sidebar/top-bar 等各处手写的 iconBtn class

**input.tsx + input.module.css**
```tsx
<Input value={...} onChange={...} placeholder={...} mono? password? />
<Textarea ... autoGrow? />
```
- 统一 border + focus(border-accent) 样式
- 消除 settings/input-bar 各处手写的 input/valueBtn/select 样式不一致

**card.tsx**
```tsx
<Card title="..." icon={...} collapsible? defaultOpen?>
  {children}
</Card>
```
- 统一 bg(--color-card) + border + radius-md + header + body 布局
- 替代 settings 的 SettingsCard/subCard 和 info-panel 的 CollapsibleSection

**badge.tsx**
```tsx
<Badge variant="accent|warning|success|danger|neutral">text</Badge>
```
- 统一小标签样式（替代 settings 的 reasoningBadge、modelMeta 等）

**toggle.tsx**
```tsx
<Toggle on={...} onChange={...} />
```
- 统一开关组件，替代 settings 手写的 toggle

**tooltip.tsx**
```tsx
<Tooltip text="...">
  {children}

```
- CSS-only tooltip（hover 显示），aria-label 兜底

**index.ts** — barrel export 全部 primitives
