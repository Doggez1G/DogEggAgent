# WebUI 重新设计 — 单布局 + 可收起侧栏

## 用户诉求
- 不要多种布局切换按钮，只要一种布局
- 侧栏可以收起（收起后变为图标条），不是通过布局按钮切换
- 整体设计太 low，体验差，需要重新设计
- 交互要优雅美观

## 设计方向：ChatGPT/Linear 风格
纯色大圆角、留白充足、聊天为主、柔和层级。不用 AI 默认三件套（深黑底+酸绿强调/奶油底+衬线标题/报纸网格）。

## 要改的文件（全量重写 WebUI 组件层）

### 1. 删除布局系统
- **删除** `theme/layouts/focus.css`、`workspace.css`、`zen.css`
- **删除** `view-state.ts` 中的 `LayoutName` 类型和 layout 相关代码
- **删除** `main.tsx` 中对 layout CSS 的 import
- **删除** `app.tsx` 中 layout state、layout effect、data-layout 属性、detailPanel、Sidebar 的 layout/onLayoutChange props

### 2. 新 App 布局（单一布局）
```
┌────┬─────────────────────────────┐
│ S  │  TopBar                     │
│ i  ├─────────────────────────────┤
│ d  │                             │
│ e  │  Chat / Sessions / Settings │
│ b  │  (panel 切换)               │
│ a  │                             │
│ r  ├─────────────────────────────┤
│    │  StatusBar + InputBar       │
└────┴─────────────────────────────┘
```
- 侧栏默认展开（240px），可收起为图标条（56px，只显示图标不显示文字）
- 收起按钮放侧栏顶部品牌旁（ChevronLeft/ChevronRight 图标）
- 不再有布局切换器、主题切换在侧栏底部用小色块按钮

### 3. App 状态改动
- 删除 `layout` state + effect
- 新增 `sidebarCollapsed: boolean` state
- Sidebar props: 去掉 layout/onLayoutChange，加 `collapsed` + `onToggleCollapse`

### 4. Sidebar 重写
- 顶部：品牌 + 收起按钮
- 导航：Chat/Sessions/Settings + 目录切换 + 新建会话
- 收起态：只显示图标，hover 时 tooltip 显示名称
- 底部：主题色块按钮（3个，小圆点）
- CSS: `width: 240px` 展开 / `width: 56px` 收起，transition 过渡

### 5. app.module.css 重写
- 单一 grid 模板：`grid-template-columns: auto 1fr`（auto = 侧栏宽度，transition 动画）
- `grid-template-areas: 'sidebar topbar' 'sidebar main' 'sidebar input'`
- 删除 detailPanel / placeholder 相关 CSS
- 清理重复的 .fsList/.fsItem 块

### 6. index.html 改动
- 去掉 `data-layout="focus"`，只保留 `data-theme="catppuccin"`

### 7. view-state.ts 改动
- 删除 `LayoutName` 类型
- 删除 `WebViewState` 接口（未被使用）
- 保留 Panel/SettingsTab/ThemeName/Modal/COMMAND_TO_NAV

### 8. main.tsx 改动
- 去掉 layout CSS import（focus/workspace/zen）
- 保留 theme CSS import + animations import

### 9. 组件 CSS 精调
- sidebar.module.css: 加 collapsed 状态样式
- top-bar.module.css: 精简
- 其他组件 CSS 不大改，只清理问题（如 topbar 的 pulse-dot 缺 keyframe）

## 不改的文件
- `bridge/`、`agent/`、`server/` — 零改动
- `shared/` — 零改动
- `chat-view`、`message-block`、`input-bar`、`status-bar`、`settings`、`sessions` 组件逻辑 — 不大改，只做 CSS 调整
- 主题 CSS（catppuccin/ios-light/ios-dark）— 不改，只改消费方式
