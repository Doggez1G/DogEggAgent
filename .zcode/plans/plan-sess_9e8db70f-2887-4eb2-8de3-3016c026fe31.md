## 候选 6：修复 server 安全问题（Speculative）

**目标**：修复 CORS、detectShells、路径穿越三个安全问题。

**步骤**：
1. **CORS**：将 `routes.ts` 中的 CORS 逻辑改为读取 `Origin` header，校验是否为 localhost（`127.0.0.1`/`localhost`/`[::1]`），匹配才返回 `Access-Control-Allow-Origin: <origin>` + `Vary: Origin`，不匹配则不设置 CORS header
2. **detectShells**：从 `routes.ts` 移到独立模块 `server/src/shells/detect.ts`，用 `execFile`（无 shell）替代 `execSync`，缓存结果（模块级变量，首次调用后不再重复检测）
3. **路径穿越**：将 `serveStatic` 中的 `fileURLToPath(new URL('file://'+filePath))` + `startsWith(staticDir)` 改为 `path.resolve(staticDir, pathname)` + `path.relative(staticDir, resolved)` 检查不以 `..` 开头
