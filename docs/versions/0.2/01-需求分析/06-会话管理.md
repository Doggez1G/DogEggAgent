# R-SES 会话管理

会话是对话历史的持久化单元：可恢复、可删除、可切换工作目录、可命名。用户在项目 A 里修完 bug，明天打开 agent 能接着昨天的上下文继续干——这是会话管理的目标。

## 需求点

### R-SES-01 持久化内容

- 每个会话一份存档，包含：**完整 history**（每条用户/助手/工具消息原文，永不淘汰）、context 视图（含压缩后的摘要状态）、**会话权限提升**（整工具与范围模式，含路径解析结果）、累计用量（prompt/completion tokens、轮数）、压缩次数。
- 存档即「发生过什么 + 授权到哪 + 干到哪」的完整快照——恢复后不需要用户重新交代任何背景。

### R-SES-02 自动落盘

- 对话结束（finished / error）即自动落盘——不依赖用户手动保存。
- 落盘后侧栏会话列表同步刷新（预览文本随最后一条消息更新）。

### R-SES-03 恢复（resume）

- 恢复完整还原：消息历史（聊天区重现全部对话）、会话权限提升（restore 后同目录工具不再重复审批）、累计用量续计。
- 恢复后首轮提交即可继续——模型看到的 context 与中断前一致。

### R-SES-04 会话列表

- 列表条目含：更新时间、预览文本（最后一条消息摘要）、标题（手动/自动）、所属项目（cwd）。
- TUI 以会话选择器呈现；WebUI 侧栏按项目分组聚合。

### R-SES-05 删除

- 可删除任意会话（带确认）；删除**当前正在使用**的会话时，立即创建一个**不落盘的空会话**接管界面——防止「删了当前会话又立刻重生一个同名会话」的僵尸循环，也避免空界面。
- 接管会话首轮对话后才持久化（防僵尸会话阻塞项目删除——用户删除项目下最后一个会话时，项目才能真正消失）。

### R-SES-06 项目维度

- WebUI 侧栏按项目（cwd）分组聚合会话；项目可显式「遗忘」——删除其下全部会话后项目从侧栏消失。
- 项目分组的依据是会话存档的 cwd，不是当前工作目录。

### R-SES-07 工作目录切换（/cd）

- 运行时切换 cwd：工具执行的基准目录、权限路径归一锚点、项目级 skills/MCP 扫描根**全部随之切换**。
- 切换后项目级 skills/MCP 重新扫描并广播（新项目的技能/服务出现，旧项目的消失）。
- cwd 同步到状态栏与 @path 联想候选。

### R-SES-08 标题

- 手动命名（/rename 或面板铅笔按钮）优先于自动标题。
- 自动标题：首轮对话后单独一次 LLM 调用生成（≤32 字；reasoning 模型单独压低输出预算）。
- 标题变更同步侧栏与状态栏。

### R-SES-09 会话隔离（权限）

- 会话权限提升只在本会话生效：新建/切换会话清空提升集；恢复会话按存档还原提升。
- 配置三桶是持久的，跨会话不变——隔离的只有「用户在本会话内点过的始终允许」。

### R-SES-10 用量累计

- 会话累计 prompt/completion tokens 与轮数持久化，跨刷新续计。
- 与「当前 context 估算」口径分离：累计包含已被压缩掉的历史用量，大于当前估算属预期（面板注明）。

## 边界与立法

- history 永不淘汰是全局立法；会话删除是用户显式行为，不受此约束。
- 会话存档不包含 MCP 连接状态——恢复后 MCP 按当前配置重新连接（工具可用性由当前配置决定）。
