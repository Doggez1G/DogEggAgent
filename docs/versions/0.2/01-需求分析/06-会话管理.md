# R-SES 会话管理

会话是对话历史的持久化单元：可恢复、可删除、可切换工作目录、可命名。

## 需求点

- **R-SES-01 持久化**：每会话一份存档——完整 history、context 视图、会话权限提升（含范围模式）、累计用量、压缩次数。
- **R-SES-02 自动落盘**：对话结束（finished/error）即落盘；侧栏列表同步刷新。
- **R-SES-03 恢复**：resume 完整还原消息历史与权限提升（restore）；恢复后首轮可继续对话。
- **R-SES-04 列表**：会话列表含更新时间、预览文本、标题、所属项目（cwd）；按项目分组展示。
- **R-SES-05 删除**：可删除任意会话；删除**当前**会话立即创建一个不落盘的空会话接管界面（避免「删了又重生」的僵尸会话）。
- **R-SES-06 项目维度**：WebUI 侧栏按项目聚合会话；项目可被显式遗忘（删除其下全部会话即消失）。
- **R-SES-07 工作目录切换**：`/cd` 运行时切换 cwd——影响工具执行、权限路径归一、项目级 skills/MCP 的扫描根。
- **R-SES-08 标题**：手动命名（/rename 或面板铅笔）优先；自动标题随首轮生成（见 R-DLG-10）；标题同步到侧栏与状态栏。
- **R-SES-09 会话隔离**：权限会话提升随会话存续——新建/切换会话清空，恢复会话按存档还原。
- **R-SES-10 用量累计**：会话累计 prompt/completion tokens 与轮数持久化，跨刷新续计（与「当前估算」口径分离）。

## 边界与立法

- history 永不淘汰是全局立法；会话删除是用户显式行为，不受此约束。
- 当前会话删除后创建的接管会话**不立即落盘**——首轮对话后才持久化（防僵尸会话阻塞项目删除）。
