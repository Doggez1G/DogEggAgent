# R-TLB 工具系统-内建

7 个内建工具覆盖「读写文件 + 执行命令 + 探索目录」的基本面。全部实现同一契约、注册进同一注册表、走同一权限网关——MCP 等外部工具接入时也遵循这套契约（见 04-工具系统-MCP）。

## 通用需求（所有内建工具共享）

### R-TLB-00 统一契约

- 每个工具实现 `execute(args, ctx)`，返回 `{ content }`（成功）或 `{ error }`（失败）——错误是**给模型看的信息**，不是异常：工具失败会作为结果回填模型自行决策，不终止对话。
- `ctx` 携带：`cwd`（当前工作目录，/cd 后变化）、`signal`（取消信号，见 R-DLG-05）、`shellProgram`（仅 shell）。
- 参数经工具自带的 zod schema 校验（模型输出非法参数 → 校验失败回填模型）。
- 超长输出经输出治理（截断并注明），避免单次工具结果撑爆上下文。

### R-TLB-08 统一注册表与合规关口（ADR-0012）

- 所有工具在唯一注册表注册/摘除；`schemas()` 每次现算——注册表变化即时反映到模型请求。
- 注册关口三职责：①名称合规（LLM 可见名必须满足供应商规定 `[a-zA-Z0-9_-]{1,64}`，不合规则整体哈希为 `h-<12hex>` 确定性标签）；②冲突可见失败（同名注册抛错，绝不静默覆盖）；③身份记录（每个工具携带来源身份 builtin/mcp）。
- 典型失败模式防 conquered：一个命名非法的 MCP server 不允许让「每一次对话请求整体 400」。

## 内建工具需求点

### R-TLB-01 read_file 读取文件

- 读取文件全文返回给模型；路径支持相对（cwd）/绝对。
- 权限按「真实位置」判定：路径先经 realpath 归一（符号链接指向 cwd 外 → 权限失配落 ask，防逃逸，ADR-0010）。

### R-TLB-02 write_file 写入文件

- 写入/新建文件（可创建多级目录）；权限按「将落入的真实父目录 + 文件名」判定——新建文件也走完整权限判定。
- 覆盖已有文件是显式行为：内容整体替换，不做合并。

### R-TLB-03 edit_file 编辑文件

- 精确替换：提供旧片段与新片段，旧片段在文件中唯一命中才执行（多处命中 → 报错回模型，要求扩大上下文）。
- 回执携带**真实行号锚点**，UI 据此渲染 diff（改了哪几行一目了然）。

### R-TLB-04 shell 执行命令

- 在**配置的解释器**中执行命令，解释器可配：cmd（Windows 默认）/ powershell（5.1）/ pwsh（7+）/ bash / sh（非 Windows 默认）。
- 配置的解释器经**本机 PATH 扫描**校验：扫描不存在的解释器 → 回退平台默认（配置了不存在的 bash 不会导致全部命令失败）。
- **模型必须感知解释器**：系统提示注入当前 Shell 环境段（解释器种类、语法差异提示）——模型的 shell 先验来自训练数据（Unix 偏置），不注入则频繁用错语法（本功能的需求来源）。
- 单命令超时（默认 120s）：超时终止整个进程树，已产生的输出回填模型（交互式常驻进程不会卡死对话）。
- 权限按 command 平文本通配匹配（详见 05-权限与安全 的主参数表）。

### R-TLB-05 ls / glob / grep 探索三件套

- `ls`：目录列举；`glob`：按模式筛文件（`**` 跨层、`*` 单段）；`grep`：内容搜索。
- 三者共享同一个目录遍历器：遵循项目 `.gitignore`（支持注释、目录限定、锚定、`!` 取反、`*`/`**`/`?` 通配的核心子集）——`node_modules` 这类被忽略目录不进结果、不进遍历。
- 权限按 path 主参数判定（与 read_file 同族）。

## 边界与立法

- 工具集是封闭枚举：新增内建工具需要实现 Tool 契约 + 注册 + 权限主参数登记（`PRIMARY_SPECIFIER`）+ 文档同步。
- MCP 等外部工具**不修改**内建工具集，只向注册表追加（见 04-工具系统-MCP）。
