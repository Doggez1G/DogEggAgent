# R-TLB 工具系统-内建

7 个内建工具覆盖「读写文件 + 执行命令 + 探索目录」的基本面。全部经统一注册表暴露给模型，全部走权限网关。

## 需求点

- **R-TLB-01 read_file**：读取文件全文；路径归一为绝对 posix 后交权限判定（realpath 防符号链接逃逸）。
- **R-TLB-02 write_file**：写入/新建文件；新文件的权限按「真实父目录 + 文件名」判定。
- **R-TLB-03 edit_file**：精确替换文件片段；回执携带真实行号锚点，UI 呈现 diff。
- **R-TLB-04 shell**：在配置的解释器中执行命令——
  - 解释器可配（cmd / powershell 5.1 / pwsh 7+ / bash / sh），配置值经**本机 PATH 扫描**校验，不在扫描结果内回退平台默认；
  - 模型可感知当前解释器（系统提示注入 Shell 环境段——模型零 shell 环境先验）；
  - 单命令超时（默认 120s，超时杀进程树并回填已有输出）。
- **R-TLB-05 ls / glob / grep**：目录列举、glob 模式筛文件、grep 内容搜索——三者共享遍历器，遵循项目 `.gitignore`（gitignore 核心子集：注释/目录限定/锚定/`!` 取反/通配）。
- **R-TLB-06 统一契约**：所有工具实现 `execute(args, ctx) → { content } | { error }`；ctx 携带 cwd / abort 信号 / shell 解释器。
- **R-TLB-07 统一注册表**：工具在唯一注册表注册/摘除（MCP 工具同表）；`schemas()` 现算暴露给模型。
- **R-TLB-08 合规关口**：注册表是 LLM 可见名的唯一关口——名称符合供应商规定（`[a-zA-Z0-9_-]` ≤64）原样注册，否则整体哈希为 `h-<12位hex>` 确定性标签；冲突可见失败；每个工具带来源身份（ADR-0012）。

## 边界与立法

- 工具结果超长时有输出治理（截断/归纳），避免撑爆上下文。
- 内建工具名是权限桶键空间的「内建保留名」（MCP 服务键 `mcp:` 前缀与之一一对应，见 05-权限与安全）。
