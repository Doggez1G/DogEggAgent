# R-DLG 对话核心

与 LLM 的多轮对话循环是产品核心：用户提交一条消息，agent 驱动模型思考、调用工具、观察结果、继续思考，直到产出最终回复。所有其它功能域都为这条循环服务。

## 需求点

- **R-DLG-01 流式响应**：模型产出的正文与思考内容分别实时流式渲染（text_delta / thought_delta 双通道），用户无需等待完整回复。
- **R-DLG-02 多轮上下文**：完整对话历史持久保存（R1 立法：永不淘汰），模型每轮看到的 context 视图与 history 分离（R2 双写）——压缩只影响 context，不碰 history 原文。
- **R-DLG-03 工具调用循环**：模型可在回复中请求调用工具；agent 执行后把结果回填模型，循环继续，直到模型产出不含工具调用的最终回复。一轮对话可含多次工具调用。
- **R-DLG-04 上下文压缩**：context 估算超过窗口 **80%** 时自动触发压缩——把当前完整 context 交给模型做「任务交接总结」（结构化提示词：任务目标/已完成步骤/涉及文件/决策/未完成事项），替换为一条摘要消息。手动 `/compact` 走同一路径（ADR-0011）。
- **R-DLG-05 压缩语义**：无保留尾巴、无淘汰、无硬丢弃；摘要失败 → 该轮以 error 收尾（诚实失败），用户可重试。
- **R-DLG-06 取消**：对话进行中可随时取消——正在执行的本地工具收到 abort 信号，循环终止，状态回落。
- **R-DLG-07 错误重试**：LLM 请求/轮次失败时，原始输入自动回填输入框，用户可直接重试。
- **R-DLG-08 迭代上限**：`maxIterations` 限制一轮对话内的工具调用轮数（`-1` 无限默认；正整数供无人值守批处理；`0` 非法）。
- **R-DLG-09 请求重试**：`maxRetries` 控制 LLM 请求失败重试次数（默认 3）。
- **R-DLG-10 会话标题**：首轮对话后自动生成标题（≤32 字，reasoning 模型单独限输出）；手动 `/rename` 优先于自动标题。

## 边界与立法

- 压缩 = 全量交接总结，不存在「摘要的摘要」叠加劣化（ADR-0011）。
- 工具调用必须经过权限网关（见 05-权限与安全），未命中规则一律询问。
- context 分段统计（system/user/assistant/tool/tools）在信息面板可见，并与 API 实际用量并排展示（估算器可校准）。
