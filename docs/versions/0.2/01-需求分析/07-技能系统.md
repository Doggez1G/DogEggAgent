# R-SKL 技能系统

Skills 是用户可编写的「指令包」：一个目录 + 一份 SKILL.md，让模型在合适的场景按需读取详细指令执行。兼容主流 Agent Skills 格式。

## 需求点

- **R-SKL-01 目录规范**：只扫两级——用户级 `~/.dogegg/skills/`、项目级 `<repo>/.dogegg/skills/`（随仓库共享）；skill 名 = 目录名，格式 `[a-z0-9][a-z0-9-]*`。
- **R-SKL-02 文件格式**：每个 skill 一个目录，入口 `SKILL.md`，frontmatter 声明 `name`（可省，缺省取目录名）与 `description`（模型判断何时使用的唯一依据）。
- **R-SKL-03 渐进披露**：系统提示只注入一行广告（名字 + 描述 + 路径）；模型判断相关后用 read_file 读取 SKILL.md 全文——无 skill 时整段不注入（省上下文）。
- **R-SKL-04 调用**：`/<skill名>` 斜杠命令触发；正文 `$ARGUMENTS` 占位符替换为命令参数（无占位且有参时追加说明段）。
- **R-SKL-05 同名覆盖**：项目级同名 skill 覆盖用户级（调用与联想取项目级）；面板两组都可见。
- **R-SKL-06 CRUD**：TUI /skills 与 WebUI 设置均支持新建（骨架生成）/ 编辑（$EDITOR 或全文编辑框）/ 删除（整目录，幂等）。
- **R-SKL-07 启停**：每个 skill 可停用/启用——停用 = 退出系统提示、斜杠联想与调用（文件保留）；状态存旁挂名单文件（用户级 `~/.dogegg/.skills.json`、项目级 `<repo>/.dogegg/.skills.json`，形状 `{ "disabled": [...] }`，缺省即启用）。
- **R-SKL-08 缺失态**：停用名单在案但目录已被外部删除的条目以「文件缺失」可见（供清理），永不进提示与调用；删除 skill 同步清理名单。
- **R-SKL-09 主流格式零污染**：启停状态绝不写进 SKILL.md（外部安装的 skill 文件不可安全重写）；状态文件损坏视为空名单自愈。
- **R-SKL-10 重建语义**：同名重建（停用后删除再创建）默认启用——创建是显式的新开始。

## 边界与立法

- 解析失败的 SKILL.md 以「解析失败」条目可见（不隐身），便于诊断。
- 调用与广告的命中都在「可用条目」内按项目覆盖用户优先——项目级停用时同名用户级照常生效。
