# R-SKL 技能系统

Skills 是用户可编写的「指令包」：一个目录 + 一份 SKILL.md，描述「什么时候用、怎么干」。模型在合适场景按需读取全文执行——把领域知识、工作流程、模板沉淀为可复用、可共享的资产。兼容主流 Agent Skills 格式（外部/npx 安装的 skill 包可直接放入目录使用）。

## 需求点

### R-SKL-01 目录规范

- 只扫两级：用户级 `~/.dogegg/skills/`（个人所有项目可用）、项目级 `<repo>/.dogegg/skills/`（随仓库共享）。
- skill 名 = 目录名，格式 `[a-z0-9][a-z0-9-]*`（小写字母/数字开头，含连字符）——也是未来的斜杠命令名。

### R-SKL-02 文件格式（主流 Agent Skills 兼容）

- 每个 skill 一个目录，入口文件 `SKILL.md`。
- frontmatter 声明元数据：`description`（模型判断何时使用的**唯一依据**，必须写得能区分场景）；`name` 可省（缺省取目录名）。
- 正文即指令：模型命中场景后读取全文照做。目录内可放附属资源（模板/脚本），由正文指引模型按需读取。

### R-SKL-03 渐进披露（上下文成本控制）

- 系统提示只注入一行广告：`- 名字：描述（路径）`——模型凭描述判断相关性。
- 命中后模型**自己用 read_file 读取** SKILL.md 全文获得详细指令——不命中就不读，几十个 skill 的上下文成本也只是几十行。
- 无任何 skill 时整段不注入（省上下文）。

### R-SKL-04 调用

- 斜杠命令 `/<skill名>` 触发（命令参数作为 `$ARGUMENTS`）。
- 正文含 `$ARGUMENTS` 占位符 → 替换为参数；无占位且有参 → 参数追加为「用户参数」段。
- 调用渲染结果作为用户消息进入对话轮次（模型按指令执行）。

### R-SKL-05 同名覆盖

- 项目级与用户级可存在同名 skill：调用与联想**取项目级**（项目定制优先）；面板两组都可见。

### R-SKL-06 CRUD

- TUI /skills 与 WebUI 设置同等支持：新建（生成骨架 SKILL.md：frontmatter + 空正文，引导用户充实）、编辑（TUI 用 $EDITOR 系统编辑器；WebUI 用全文编辑框）、删除（整目录删除，幂等，带确认）。
- CRUD 全部限定在两级根目录内（名称校验 + 路径越界双保险）。

### R-SKL-07 启停

- 每个 skill 可停用/启用（TUI `t` 键 / WebUI 按钮）。
- 停用 = 同时退出三个生效面：系统提示广告、斜杠联想、调用（文件保留，随时恢复）。
- 状态存**旁挂名单文件**（与 `.mcp.json` 同构）：用户级 `~/.dogegg/.skills.json`、项目级 `<repo>/.dogegg/.skills.json`，形状 `{ "disabled": ["名字", ...] }`——缺省即启用；项目级停用随 `.dogegg/` 进 git 与仓库共享。
- 主流 SKILL.md 格式**零污染**：启停状态绝不写进 skill 文件（外部安装的文件不可安全重写）。

### R-SKL-08 缺失态（孤儿）

- 停用名单在案、但 skill 目录已被外部删除（手动/git/换分支）→ 条目以「文件缺失」可见（灰显 + 标注），**永不进提示与调用**。
- 清理 = 启用该条目（移除孤儿记录）；删除缺失条目同样等价清理。
- 单个 skill 目录被删 → 该条目孤儿可见；整个 skills 目录被删 → 名单内全部条目可见。

### R-SKL-09 格式自愈

- 状态文件损坏/形状不符 → 视为空名单（全部启用），skills 功能不拖垮；用户删状态文件即完全重置。
- 解析失败的 SKILL.md（frontmatter 坏）以「解析失败」条目可见——不隐身，便于定位修复。

### R-SKL-10 重建语义

- 同名重建（停用后删除再创建）默认启用——创建是显式的新开始，自动移除停用名单中的同名记录。

## 边界与立法

- 调用与广告的命中都在「可用条目」（enabled 且非缺失）内按项目覆盖用户优先——项目级停用时同名用户级照常生效。
- 名称校验双保险：NAME_RE + 路径越界检查（join 后必须仍在根目录内）。
- 启停与 MCP server 启停同构（toggle 消息、面板键位、UI 交互），但 skills 无运行进程——纯声明式的可用性开关。
