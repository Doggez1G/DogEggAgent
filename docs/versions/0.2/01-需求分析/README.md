# 01-需求分析

本模块回答「DogEggAgent 应该做什么」：按功能域拆解需求点与验收行为。每篇文档对应一个功能域，需求点编号 `R-<域缩写>-<序号>`，均为**已实现**状态（0.2）。

## 功能全景

| 文档 | 功能域 | 一句话定位 |
|---|---|---|
| [01-对话核心](./01-对话核心.md) | R-DLG | 与 LLM 的多轮对话循环：流式、工具调用、压缩、取消 |
| [02-模型接入](./02-模型接入.md) | R-LLM | 多 provider/model 管理与 OpenAI 兼容接入 |
| [03-工具系统-内建](./03-工具系统-内建.md) | R-TLB | 7 个内建工具（读写编辑/shell/探索三件套） |
| [04-工具系统-MCP](./04-工具系统-MCP.md) | R-MCP | MCP 服务器接入：连接生命周期、工具注册、启停 |
| [05-权限与安全](./05-权限与安全.md) | R-PRM | 三桶权限、参数模式、服务键、审批流、安全默认 |
| [06-会话管理](./06-会话管理.md) | R-SES | 会话持久化、恢复、删除、工作目录切换、标题 |
| [07-技能系统](./07-技能系统.md) | R-SKL | SKILL.md 技能包：目录规范、渐进披露、调用、启停 |
| [08-TUI交互](./08-TUI交互.md) | R-TUI | 终端界面：命令、面板、表单、审批、联想 |
| [09-WebUI交互](./09-WebUI交互.md) | R-WEB | 浏览器界面：聊天、设置、信息面板、Cmd+K |

## 需求点的书写约定

- 每个需求点 = 一句可验收的行为描述 + 必要的边界说明。
- 「安全默认」「固定安全默认」指**不可被配置关闭**的兜底行为（未命中任何规则 → ask）。
- 涉及跨版本语义决策的需求点会标注 ADR 编号（如 ADR-0013）；完整决策见 `docs/adr/`。
- 需求与实现有出入时，以实现为准并视为文档缺陷——请提 issue 或直接修订。
