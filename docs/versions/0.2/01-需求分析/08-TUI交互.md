# R-TUI TUI交互

终端界面（Ink）：已完成的内容打印进终端滚动缓冲区（Static 区，用终端原生滚动看历史），底部动态区承载输入、流式与全部弹层。键盘是第一交互方式，鼠标可选。

## 需求点

### R-TUI-01 命令集

- 斜杠命令：`/help`（帮助）/ `/config`（配置树）/ `/model`（选模型）/ `/mcp`（MCP 管理）/ `/skills`（技能管理）/ `/permissions`（会话提升查看与撤销）/ `/new`（新会话）/ `/rename`（命名）/ `/cd`（切目录）/ `/compact`（手动压缩）/ `/context`（上下文详情）/ `/status`（状态）/ `/system`（系统提示词）/ `/log`（日志尾部）/ `/tools`（工具清单）/ `/quit`（退出）。
- 斜杠联想：输入 `/` 弹候选（内建命令 + skill 动态命令），↑↓ 选择、Tab 唯一匹配补全；停用/缺失的 skill 不出现。
- 输入历史：↑↓ 召回历史提交（含跨会话）。

### R-TUI-02 /config 配置树

- 树形编辑器：根层（systemPrompt/defaultProvider/defaultModel/maxIterations/maxRetries/shellProgram/主题/permission/providers/mcpServers 入口）→ 逐层钻入。
- 行交互：标量 Enter 输入、布尔 ←→ 切换、枚举选择、数组增删（d 键删除）。
- 权限子树：三桶 → 键列表 → 细化编辑（见 R-TUI-03）。
- providers 子树：provider/model 增删改（校验放宽，逐字段填写）。

### R-TUI-03 权限细化编辑

- 权限选择器（selectTool）：内建工具逐个 + MCP 服务整组（标注工具数/未运行）——**选择即钻入**：选中后直接落到该键的细化层，免 esc 往返。
- 细化层两态：整选开关（whole）恒可用 + 模式行就地编辑（scalar 改名/删除）+ 添加模式；服务键为**勾选式**（对运行时工具清单勾选 + 通配规则行）。
- 跨桶提示：同一键在其它桶也有规则时显示提示（防「已放行为什么还问」困惑）。

### R-TUI-04 表单视图（/mcp、/skills 新建编辑）

- 一屏多字段表单：↑↓ 在字段与保存行之间循环；Enter 编辑文本字段（弹输入框，esc 回表单不丢已改内容）/ 循环切换选项字段（如落点、传输类型）；s 或保存行提交。
- 校验失败（名称空/JSON 非法/格式不符）提示后**留在表单**——已填内容不丢。
- 编辑态身份字段锁定（名称/落点不可改——名称即身份）。

### R-TUI-05 弹层层级（esc 语义）

- 全部弹层（菜单/信息/表单/输入框）支持 returnView 回退链：面板内钻入的详情与确认菜单，esc **回到来源视图**；只有来源是主屏的弹层 esc 才关面板。
- 任何设置流程中，esc 逐级回退，不存在「一次 esc 丢失整个面板层级」。

### R-TUI-06 审批层

- ask 调用弹出审批层：工具名 + 参数 + 四档决策（本次允许 / 始终允许 / 对此范围不再询问 / 拒绝）。
- 范围模式自动推导（shell 按命令首词、文件类按所在目录）并随决策落库。
- 决策期间对话暂停（状态机 waiting_permission），决策后继续。

### R-TUI-07 @path 路径联想

- 输入 `@` 触发 cwd 内文件路径补全：目录优先、逐层下钻（`@src/` 再弹子层）、↑↓ 选择、Tab/回车补全。
- esc 关闭联想（本次输入变化前不再弹出）。

### R-TUI-08 浏览模式

- Ctrl+↑↓ 在已完成的消息块间移动焦点（含工具块），Enter 切换折叠/展开，esc 退出浏览。
- 展开按工具类型精修：命令与输出分层、edit_file 渲染 diff 带真实行号。

### R-TUI-09 状态栏

- 常驻底部一行：状态机状态、provider/model、会话名、token 估算/窗口、会话累计用量、cwd、git 分支。
- 切换模型/配置后即时刷新（不等下一轮对话）。

### R-TUI-10 主题

- 多主题（dawn/forest/midnight 等），/config 内切换即时生效；主题只控制颜色 token，不改变布局。

## 边界与立法

- 键盘路由：全局拦截（Ctrl+C）→ 按 view.kind 分派到各 feature 的 keys 处理器（纯逻辑、可单测）。
- Static/动态分层是渲染立法：Static 区打印一次即进终端缓冲（历史），Ink 只重绘底部动态区。
- 视图态（overlay 栈）是 UI 私有状态，与后端状态机正交；读 state 的按键处理必须走 ref 镜像（Ink 闭包旧值教训）。
