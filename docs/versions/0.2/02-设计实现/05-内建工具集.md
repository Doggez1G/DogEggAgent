# 05-内建工具集

7 个内建工具（`agent/src/tools/`）：read_file / write_file / edit_file / shell / ls / glob / grep。全部实现 `Tool` 契约并走统一权限网关。

## 实现要点

- **read_file**：全文读取；权限前参数归一为「真实绝对 posix 路径」（realpath 防符号链接逃逸——cwd 内链接指向 cwd 外即失配落 ask，ADR-0010）。
- **write_file**：可创建多级目录；新建文件的权限按「真实父目录 + 文件名」判定。
- **edit_file**：旧片段**唯一命中**才替换（多处命中报错回模型要求扩大上下文）；回执携带真实行号锚点供 UI 渲染 diff。
- **shell**（`tools/shell/`）：
  - 解释器选择：配置 `shellProgram`（cmd/powershell/pwsh/bash/sh），经**本机 PATH 扫描**校验，不在扫描结果内回退平台默认；
  - 解释器种类（kind）注入系统提示（Shell 环境引导段）——模型零 shell 先验，不注入会频繁用错语法；
  - 单命令超时（默认 120s）：超时杀进程树、已产输出回填模型；
  - 权限主参数是 command（平文本通配）。
- **ls / glob / grep**（共享 `tools/traverse/` 遍历器）：
  - 遍历遵循 `.gitignore` 核心子集（注释/目录限定/锚定/`!` 取反/`*` `**` `?`）——单条规则非法跳过不拖垮整体；
  - grep 支持内容搜索；权限按 path 主参数（分段 glob）。
- **输出治理**：超长结果截断并注明，保护上下文预算。

## 与其它域的接缝

- 权限：执行前经 PermissionManager.classify（realpath 归一在权限侧完成）。
- 身份：内建工具注册时默认 `{ kind: 'builtin' }` 身份。
- 取消：ctx.signal 直达（shell 超时/用户取消都终止进程树）。
