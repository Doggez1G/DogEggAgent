# 09-会话与持久化

`agent/src/session/manager.ts` + `store.ts`：会话是「发生过什么 + 授权到哪 + 干到哪」的完整存档。

## 存档内容

- 完整 history（消息原文，永不淘汰）、context 视图、会话权限提升（tool → patterns，含路径解析结果）、累计用量（prompt/completion/轮数）、压缩次数。
- 对话结束（finished/error）自动落盘；保存路径默认 `~/.dogegg/sessions/`（可注入接缝）。

## 恢复（resume）

- 重建消息历史（聊天区重现）、还原权限提升（restore）、用量续计——恢复后首轮即可继续。
- 恢复不影响运行体：MCP 按当前配置重连，工具可用性由当前配置决定。

## 删除语义

- 删除任意会话（确认后）；删除**当前**会话 → 立即创建一个不落盘的空会话接管界面（首轮对话后才持久化）——防「删了重生」僵尸循环，也让项目下最后一个会话真正可删（项目遗忘的前提）。

## 项目分组与 cwd

- 会话存档携带 cwd——UI 按项目分组；`/cd` 切换的是**当前工作环境**（工具 cwd、权限锚点、项目级 skills/MCP 扫描根），不改变已有会话的归属。
- 项目「遗忘」= 删除该项目下全部会话。

## 权限隔离

- 会话提升随会话存续：新建/切换清空，恢复按存档还原——配置三桶持久，提升临时，两者独立。
