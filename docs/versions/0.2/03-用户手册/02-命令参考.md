# 02-命令参考

斜杠命令在 TUI 与 WebUI 通用（输入 `/` 触发联想）。`<skill名>` 形式的命令来自技能系统，与内建命令同池联想。

## 命令全表

| 命令 | 说明 |
|---|---|
| `/help` | 显示帮助 |
| `/config` | 打开配置编辑器（TUI 配置树 / WebUI 设置弹框） |
| `/model` | 快速切换模型（provider 下的模型列表） |
| `/mcp` | MCP 服务器管理面板（增删改/启停，Enter 查看详情与工具清单） |
| `/skills` | 技能管理面板（新建/编辑/启停/删除） |
| `/permissions` | 查看/撤销本会话内的权限提升（始终允许/范围提升） |
| `/new` | 新建会话（权限会话提升清空） |
| `/session` | 切换会话（选择器） |
| `/rename <名称>` | 重命名当前会话（手动命名优先于自动标题） |
| `/cd <路径>` | 切换工作目录（工具执行基准、项目级 skills/MCP 扫描根随之切换） |
| `/compact` | 手动压缩上下文（与自动压缩同路径） |
| `/context` | 查看上下文占用（分段统计 + 三口径用量） |
| `/status` | 状态一览（会话/模型/状态/用量） |
| `/system` | 查看当前系统提示词全文（含 skills 广告段与 shell 环境引导） |
| `/log` | 查看调试日志尾部 |
| `/tools` | 列出当前可用工具（按来源分组） |
| `/clear` | 清空当前会话历史 |
| `/quit` | 退出（Ctrl+C 空闲时等同） |
| `/<skill名> [参数]` | 调用技能（`$ARGUMENTS` 替换为参数；停用/不存在的 skill 不可调用） |

## 权限决策（审批弹层四档）

工具调用落 `ask` 桶时弹出审批，四档决策的含义与后果：

| 决策 | 生效范围 | 何时选 |
|---|---|---|
| **允许一次** | 仅本次调用 | 一次性操作 |
| **始终允许** | 本会话内该工具全部调用（整工具提升） | 同类操作预期多次 |
| **对此范围不再询问** | 本会话内该工具的**推导范围**调用（shell 按命令首词、文件类按所在目录） | 只想放行某类操作 |
| **拒绝** | 本次不执行，模型收到拒绝原因 | 不希望执行（模型会调整方案） |

- 「对此范围不再询问」仅在能自动推导出范围时出现（推导不出时只有三档）；shell 类范围含该前缀的一切命令（含 `&&` 命令链）。两端按钮顺序略有差异：TUI 为 允许一次 → 始终允许 → 对此范围不再询问 → 拒绝；WebUI 审批横幅为 Allow Once → Always Allow: <范围> → Always Allow (tool) → Reject。
- 「始终允许/范围」是**会话级**授权：/permissions 可查看与撤销，新建会话清空。
- 配置层 reject 恒压过会话提升；配置层 ask 会被会话提升压过（提升 = 用户最新意图）。

## 权限判定顺序（速查）

```
reject 命中 → 拒绝
会话提升命中 → 放行
ask 命中 → 审批
allow 命中 → 放行
全部未命中 → ask（固定安全默认）
```

MCP 服务键规则（`mcp:<服务名>`）的 whole/勾选语义见 [01-配置指南](./01-配置指南.md) 的 permission 章节。
