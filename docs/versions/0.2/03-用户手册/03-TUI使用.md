# 03-TUI使用

终端界面的操作说明。界面分两层：历史消息打印进终端滚动缓冲区（终端原生滚动查看）；底部动态区承载流式输出、输入框与全部弹层。底部状态栏常驻显示状态、provider/model、会话名、用量、cwd。

## 输入与对话

- 直接输入文本回车即提交；模型回复流式渲染（思考内容折叠呈现）。
- 工具调用块可折叠/展开（浏览模式 Ctrl+↑/↓ 移动焦点，Enter 切换）——思考内容块同理（折叠标签提示「浏览模式 Enter 展开」）；工具块展开后命令与输出分层、编辑操作渲染 diff 带真实行号。
- `@` 触发路径联想（cwd 内，目录优先逐层下钻），Tab/回车补全——适合快速引用文件。
- 运行中提交的消息不会被发送：提示「运行中，请稍候——本条未发送」，输入保留、任务结束后可直接重发（输入框运行中不禁用，可继续打字）；未知 `/xxx` 提示「未知命令」并保留输入（不弹帮助页）。
- 出错时上次输入自动回填，直接重试。

## /config 配置树

- ↑↓ 选条目，**Enter** 钻入/编辑，←→ 切布尔或返回上级，**d** 删除条目，**esc** 逐级返回（根层关闭）。
- permission 子树：三桶 → 键列表 → 细化层：
  - 细化层顶部是**整选开关**（✓ 整工具生效 / · 按模式限定）——回车切换，已配模式保留恢复；
  - 模式行 Enter 就地改名、`d` 删除；「＋ 添加模式」新增；
  - MCP 服务键钻入后是**勾选式**：对运行时工具清单勾选/取消 + 通配规则行。
- 权限选择器（添加工具）：内建工具逐个 + MCP 服务整组；**选中即钻入**细化层。

## /mcp 与 /skills 面板（表单流）

两个管理面板操作一致：

- ↑↓ 选择条目；Enter 查看详情（工具清单/全文）；`a` 新建、`e` 编辑、`t` 启停（skills）/ 停用（mcp）、`d` 删除（确认菜单）；esc 回退。
- 新建/编辑进入**表单视图**：一行一字段——
  - Enter 编辑文本字段（弹输入框，esc 回表单不丢已改内容）；
  - 选项字段（落点/传输类型）Enter 循环切换；
  - `s` 或保存行回车提交；校验失败提示后留在表单（已填内容不丢）；
  - esc 回列表不保存。
- 编辑 server/skill 时身份字段（名称/落点）锁定；编辑停用中的 MCP server 不会误启用。

## 审批层

ask 工具弹出审批层：显示工具与参数，四档决策（见 02-命令参考）。选择「对此范围不再询问」时自动推导范围（shell 按命令首词、文件类按所在目录）。

## 其它面板

- /permissions：列出本会话提升，回车撤销（带模式的下钻逐条撤）。
- /context /status /system /log /tools：信息面板，↑↓ 翻页，esc 关闭。
- /model：模型快速切换；/cd：目录切换（输入路径回车提交，路径不存在会提示）。

## 提示

- 所有面板内 esc 逐级回退，不会一次丢掉整个面板层级。
- 配置校验失败（如模式缺作用域锚点）会显示具体原因——按提示修正即可。
